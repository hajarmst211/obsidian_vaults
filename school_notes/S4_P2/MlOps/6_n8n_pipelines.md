
### **2. n8n : Automatisation et Productivité**
n8n est présenté comme un outil d'automatisation **No-Code/Low-Code** open source et gratuit, idéal pour l'IA agentique.

*   **Objectif :** Connecter différents systèmes (bases de données, applications SaaS, API REST) pour automatiser des tâches répétitives.
*   **Avantage du "Gain de Temps" :** L'automatisation permet donc une efficacité de type "effet de cascade".
*   **Fonctionnement :** 
    *   Interface basée sur des nœuds (noeuds réguliers et déclencheurs).
    *   Gestion de données dynamiques via des expressions.
    *   Capacité à manipuler et analyser les données entre les systèmes.

---

### **3. Intégrations et MCP dans n8n**
*   **Community Nodes :** n8n permet d'installer des nœuds développés par la communauté (via *Settings > Community Nodes*) pour étendre les fonctionnalités nativement (ex: envoi de SMS, messageries comme Telegram/WhatsApp).
*   **MCP Client :** n8n propose des outils (`MCP Client Tool`) permettant d'intégrer des protocoles externes pour interagir avec des outils spécialisés, comme **Firecrawl** pour le web scraping.
*   **Credentials :** L'interface facilite la gestion des clés API (DeepSeek, OpenAI, Google Gemini) pour piloter les modèles d'IA au sein des workflows.
